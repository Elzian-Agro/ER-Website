# ER-Website

This is a website of Earth Restoration.

## Instructions

1. Clone the repository: `git clone https://github.com/Elzian-Agro/ER-Website.git`
2. Navigate to the project directory: ER-Website
3. Open index.html in your web browser.

## Map Integration
- KMZ file viewer - https://earth.google.com/web/
- Convert KMZ to geoJSON - https://mapshaper.org/
- Mapbox - https://console.mapbox.com/
- Mapbox Pricing - https://www.mapbox.com/pricing#maps
- Mapbox Doc - https://docs.mapbox.com/mapbox-gl-js/guides/
